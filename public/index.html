監視設定

このWindows PCが受信した外部通信と、リモート認証・操作を収集します。

実ログの収集を開始する
  1. プロジェクト内の start-monitor.cmd をダブルクリック。
  2. Windowsの管理者権限の確認で「はい」を選択。
  3. 監査記録を有効化し、アプリを管理者として再起動します。
powershell -ExecutionPolicy Bypass -File .\start-monitor.ps1
ファイアウォール規則・公開ポートは変更しません。詳細なコマンド引数の記録は README を参照してください。過去の未記録アクセスは復元できません。
